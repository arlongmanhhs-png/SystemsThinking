# Purposes: retired

**Decided 28 September 2026.** There is no purpose field, and this folder holds no
live material. The four stubs written on 25 September are in `_retired/`.

The reasoning, in short. The process is for policy and intervention design: how to
alleviate, solve, or prevent a social or organisational challenge. Set against the
five positions asked in Step 1, three of the four drafted purposes turned out to
be the position under another name:

| The difference purpose was meant to carry | What already decides it |
| --- | --- |
| What the last steps deliver: an ask, options with a recommendation, a decision, or findings | Position, one row each in the Step 1 table |
| Whether the participant's own influence is mapped in Step 7 | Position |
| Who the Step 13 message is addressed to | Position |
| Whether Steps 8 to 11 are done at all | The case and the time available, not a declared purpose |

The fourth, evaluating an intervention that already exists, is not a purpose but a
condition of the case, and it is the only one that would change the order of the
steps. It is **out of scope for now**, by decision: an evaluative version of the
platform is worth considering later, and building it into the process at this
stage would be noise.

See `core/principles.md`, rule 3.
