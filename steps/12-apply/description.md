# Step 12. Apply the analysis

**Not yet written.** This file holds what is settled about the step: what it is
for, its critical check and its sources. What the participant does, in what
order and with what guidance, is written phase by phase in the working document
and comes here after it is settled. Do not build from this file alone.

## What the step is for

Turns the analysis into what the participant's position requires. Acting for an organisation or a cause: the actor who controls the lever, the level of governance, the arena, the instrument, the moment in the policy cycle, and the ask. Advising: options with a recommendation. Deciding: a decision. Analysing from outside: findings.

## Output

For advocacy: target actor, level, arena, instrument, ask

## Uses the output of

Step(s) 1, 2, 7, 8. See `core/critical-checks.md` for the dependency table and
the return triggers.

## The critical check

The step is complete when:

- Set per framing.
- For advocacy: every element traces back to the chosen lever in Step 8.

The criteria are self-checked. See `core/critical-checks.md`.
