# Step 4. Identify enablers and inhibitors

**Not yet written.** This file holds what is settled about the step: what it is
for, its critical check and its sources. What the participant does, in what
order and with what guidance, is written phase by phase in the working document
and comes here after it is settled. Do not build from this file alone.

## What the step is for

Collects what holds the current situation in place and what pushes against it.

## Output

Grouped factors, named as variables and typed as stocks or flows

## Uses the output of

Step(s) 1, 2, 3. See `core/critical-checks.md` for the dependency table and the
return triggers.

## The critical check

The step is complete when:

- Every factor is written as a variable: a noun, observable or measurable, neutral, and able to rise or fall.
- Each is typed as a stock (something that accumulates) or a flow (something that adds to or drains a stock).
- Factors are grouped into themes.
- The PESTLE prompt has been checked for gaps.

The criteria are self-checked. See `core/critical-checks.md`.
