# Step 5. Map the causal structure

**Not yet written.** This file holds what is settled about the step: what it is
for, its critical check and its sources. What the participant does, in what
order and with what guidance, is written phase by phase in the working document
and comes here after it is settled. Do not build from this file alone.

## What the step is for

Connects the factors into a causal loop diagram.

## Output

Causal loop diagram with polarities, loops, delays, stocks and control markers

## Uses the output of

Step(s) 1, 2, 3, 4. See `core/critical-checks.md` for the dependency table and
the return triggers.

## The critical check

The step is complete when:

- Drivers and end variables are identified.
- Every variable an actor controls carries that actor's marker, and variables no one controls are left unmarked.
- Every link has a polarity.
- Variables that are stocks (things that accumulate) are marked as stocks.
- At least one closed loop is labelled reinforcing or balancing.
- Delays are marked.
- The variable from Step 3 is in the mapping.

The criteria are self-checked. See `core/critical-checks.md`.
